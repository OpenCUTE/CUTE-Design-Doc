# CUTE 设计文档

硬件设计承担的小愿望是：将已经明确的系统组合、指令和数值约定，落实为能够协作的
RTL 部件。OpenCUTE 主文档解释 [目标如何分解](/decomposition/) 和
[组件怎样合作](/modules/)；本站继续展开每个硬件部件的结构、接口和实现。

## 从系统承诺进入部件实现

模块接受输入、配置与握手，交付计算结果和可观察的完成行为。软件、trace 和验证
依赖这些对外承诺，修改内部结构时应保持它们；改变外部含义时则要一起更新消费者。
配置和编码的定义位置见 [Only One Truth](/config-architecture/#single-truth)，具体字段见相应章节。

本文档是 CUTE 硬件加速器的微架构设计文档，面向芯片设计工程师、验证工程师和系统集成工程师，提供以下内容：

- **可参数化配置的张量核设计**：每个模块的设计参数、功能描述、微架构设计和接口信号
- **多种数据格式支持**：支持的多种混合精度(BF16\MXFP\NVFP等)格式方案
- **软件编程接口**：自定义指令编码、异步编程模型
- **基本软件测试**: 包含基本的验证测试方案介绍

本文档保留硬件设计与历史实验说明。当前配置、软件接口和已验收范围见
[OpenCUTE 主文档](/) 和 [验收状态](/status/)；历史论文或示例不等于当前工作树的完整验证。
